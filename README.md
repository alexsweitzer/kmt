# Kentmorr Marine Transport website

Plain HTML/CSS/JS. No build step, no framework. Edit any .html file in a text editor and re-upload it.

## Files
- `index.html` + 7 other pages
- `styles.css` — all styling (brand navy #0b2142, gold #fcb326)
- `script.js` — mobile menu, gallery viewer, quote form
- `images/` — web-optimized copies of the Wix originals

## Before going live
1. Quote form: create a free form at formspree.io, copy its ID, and replace `YOUR_FORM_ID` in `contact.html`.
2. Confirm the phone number and email (see notes from Claude).

## Updating the site
Edit the file, then upload it to the GitHub repo (Add file → Upload files → Commit). Live in about a minute.
